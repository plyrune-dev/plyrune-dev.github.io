A check about an immutable candidate is different from permission to write a changing workspace. Live application is a later, separately qualified protocol.

Delivery / six milestones

Prove the small path.
Then earn the larger one.

M0 / M1

Contracts and composition

Pin the sources, adopt Tauten, establish shared identities and deliver one literal migration over immutable input.

M2 / M3

Interface and reuse

Retain captures across calls. Measure the interface early. Add conservative dependency-aware revalidation.

M4 / M5

Evidence and publication

Publish controlled evaluation results. Add a live-application host only with an explicit concurrency contract.

Evaluation / proposed approach

A fair test against
the tools agents already use.

Compare native tools, a unified facade, shared captures and incremental reuse. Give every arm scripting and batching. Grade task outcomes independently.

Measure complete task cost, model roundtrips, unintended changes, missed edits and false refusals. Separate cold setup from warm reuse. Keep failures in the denominators.

Ordinary lookups and simple patches are controls. A ceiling result is published as a ceiling result. Fewer output bytes alone do not establish a better workflow.
